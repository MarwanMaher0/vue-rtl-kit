# createRtl

تنشئ `createRtl()` مخزن الاتجاه على مستوى التطبيق وإضافة Vue الخاصة به. أنشئ نسخة واحدة، ومرّرها إلى `app.use()`، واحتفظ بالمرجع نفسه عندما يحتاج إليه جزء من الشيفرة خارج المكوّنات.

```ts
function createRtl(options?: RtlOptions): RtlInstance
```

```ts
import { createApp } from 'vue'
import { createRtl } from 'vue-rtl-kit'
import App from './App.vue'

const rtl = createRtl({
  locales: { en: 'ltr', ar: 'rtl', he: 'rtl' },
  defaultLocale: 'ar',
  htmlClass: true,
  numberingSystem: { ar: 'latn' },
})

createApp(App).use(rtl).mount('#app')
```

## الخيارات

| الخيار | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `locales` | `string[] \| LocaleMap` | `{}` | اتجاهات اللغات، وليست قائمة تحصر اللغات المسموح بها. تُستنتج اتجاهات عناصر المصفوفة، أما الخريطة فتحددها صراحةً. |
| `defaultLocale` | `string` | أول مفتاح لغة، وإلا `'en'` | اللغة الابتدائية. |
| `dir` | `Direction` | يُستنتج من `defaultLocale` | الاتجاه الابتدائي الصريح. يؤدي توفيره أيضًا إلى تثبيت الاتجاه. |
| `syncDocument` | `boolean` | `true` | يحافظ على تزامن `<html dir>` و`<html lang>` في المتصفح. |
| `htmlClass` | `boolean \| { rtl: string, ltr: string }` | `false` | يبدّل الصنفين `rtl` و`ltr`، أو أسماء الأصناف المقدّمة، على `<html>`. |
| `numberingSystem` | `NumberingSystem \| Record<string, NumberingSystem>` | `undefined` | نظام الأرقام الافتراضي لـ`useFormat()`، على مستوى عام أو لكل لغة. |
| `registerGlobals` | `boolean` | `true` | يسجّل `RtlProvider` و`BidiText` و`v-rtl` عند التثبيت. |

## صيغ اللغات

تكون المصفوفة مناسبة عندما يكفي الاستنتاج المضمّن استنادًا إلى اللغة والخط:

```ts
const rtl = createRtl({ locales: ['en', 'ar-EG', 'ku-Latn'] })
```

أما الخريطة فهي صريحة ويمكنها تجاوز الاستنتاج المضمّن للغة والخط:

```ts
const rtl = createRtl({
  locales: {
    en: 'ltr',
    ar: 'rtl',
    'az-Arab': 'rtl',
  },
  defaultLocale: 'az-Arab',
})
```

## قواعد اتجاه اللغة

عندما لا يكون الاتجاه مثبّتًا، يُحدَّد اتجاه اللغة بالترتيب التالي:

1. الاتجاه المطابق للوسم كاملًا في خريطة اللغات.
2. الاتجاه المطابق للغة في الخريطة.
3. الاستنتاج المضمّن استنادًا إلى اللغة والخط.

تتقدّم اتجاهات الخريطة حتى على الخط المحدّد صراحةً. أما في الاستنتاج المضمّن، فيتقدّم الخط الصريح في جزء اللغة على اتجاه اللغة الافتراضي. يُعتدّ بالخط فقط إذا ورد قبل أول وسم فرعي من محرف واحد، مثل `u` أو `x`؛ ولا تُستنتج الخطوط من الامتدادات مثل `-u-` أو من الوسوم الفرعية للاستخدام الخاص بعد `-x-`.

| اللغة | الاتجاه المستنتج | السبب |
| --- | --- | --- |
| `ar-Latn` | `ltr` | يتقدّم الخط اللاتيني الصريح على اتجاه العربية الافتراضي. |
| `ar-u-nu-latn`، `he-x-abcd` | `rtl` | لا تغيّر وسوم الامتدادات والاستخدام الخاص الخط المعتمد. |
| `ha`، `ku` | `ltr` | الخط الافتراضي للهوسا والكردية هو اللاتيني. |
| `ha-Arab`، `ku-Arab` | `rtl` | يتقدّم الخط العربي الصريح على الخط اللاتيني الافتراضي. |
| `pnb`، `mzn`، `lrc`، `glk`، `bal`، `sdh` | `rtl` | لهذه اللغات اتجاه افتراضي من اليمين إلى اليسار. |
| `fr`، `qaa` | `ltr` | تستخدم اللغات غير المعروفة أو غير المكتوبة من اليمين إلى اليسار `ltr` إذا كان الوسم صحيح البنية، وليس القيمة الاحتياطية. |

لا تُستخدم القيمة الاحتياطية إلا للوسوم الفارغة أو غير الصالحة، وليس للغة ذات وسم صحيح البنية غير مدرجة في `locales`. مثلًا، يبدأ `createRtl({ locales: { ar: 'rtl' }, defaultLocale: 'ar' })` باتجاه `rtl`؛ ويغيّر استدعاء `setLocale('fr')` الاتجاه إلى `ltr` رغم أن `fr` غير مدرجة.

وبالمثل، يستخدم `RtlProvider` غير المثبّت ذو الخاصية `locale="fr"` الاتجاه `ltr` داخل نطاق أب باتجاه RTL، ما لم تحدّد خريطة اللغات اتجاهًا آخر. يؤدي توفير `dir` إلى تثبيت الاتجاه، فلا يغيّره تغيير اللغة.

## إلغاء التسجيل العام

عند تعطيل التسجيل العام، استورد العناصر في المواضع التي تُستخدم فيها:

```ts
const rtl = createRtl({ registerGlobals: false })
```

```vue
<script setup lang="ts">
import { BidiText, vRtl } from 'vue-rtl-kit'
</script>

<template>
  <BidiText text="الإصدار v1.2.3" />
  <code v-rtl:ltr>feature/rtl</code>
</template>
```

## التنظيف

يوقف `dispose()` مراقب المستند. وهو مفيد أساسًا في الاختبارات المعزولة أو عند إزالة تطبيق؛ ولا يلغي Vue provides أو المكوّنات العامة.

```ts
rtl.dispose()
```
