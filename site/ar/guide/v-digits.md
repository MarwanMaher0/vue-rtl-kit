# توحيد الأرقام باستخدام `v-digits`

استخدم `v-digits` عندما تريد أن يتمكّن المستخدم من إدخال الأرقام بلوحة المفاتيح التي اعتادها، وأن تصل إلى التطبيق بصيغة واحدة. مثلًا، إذا كتب `٠۰٤۲` أو لصقها في الحقل التالي، تصبح قيمة `reference` السلسلة النصية `'0042'`. احتفظ برقم الطلب كنص حتى لا تفقد الأصفار في بدايته.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { vDigits } from 'vue-rtl-kit'

const reference = ref('')
</script>

<template>
  <label>رقم الطلب <input v-model="reference" v-digits type="text"></label>
</template>
```

يكفي استيراد `vDigits` في `<script setup>` لاستخدام التوجيه دون تثبيت الإضافة. وهو متاح أيضًا باسم `digitsDirective`. أمّا إذا ثبّتَّ `createRtl()`، فيتوفّر `v-digits` على مستوى التطبيق دون استيراد، ما لم تضبط `registerGlobals: false`. وفي Nuxt تتولّى الإضافة نفسها تسجيل التوجيه وقت التشغيل؛ ولا يعتمد ذلك على الاستيراد التلقائي.

## اختيار شكل الأرقام

يقبل التوجيه قيمة اختيارية على الصورة `{ to?: 'latn' | 'arab' | 'arabext'; decimal?: boolean }`. يمكنك المزج بين الأرقام الغربية والهندية والفارسية في الحقل نفسه؛ فالخيار `to` يحدّد شكل الأرقام بعد التحويل ولا يقيّد ما يمكن إدخاله:

| صيغة التوجيه | النص المُدخل | قيمة الحقل |
| --- | --- | --- |
| `v-digits` (الافتراضي: `'latn'`) | `A-٠۱۲` | `A-012` |
| `v-digits="{ to: 'arab' }"` | `A-012` | `A-٠١٢` |
| `v-digits="{ to: 'arabext' }"` | `A-012` | `A-۰۱۲` |

القيمة الافتراضية للخيار `decimal` هي `false`، فتظل علامات الترقيم كما أُدخلت. مع `decimal: true` تتحوّل الفاصلة العشرية العربية `٫` (U+066B) إلى نقطة `.` ويُحذف فاصل الآلاف العربي `٬` (U+066C). مثلًا، يحوّل الإعداد `{ to: 'latn', decimal: true }` القيمة `١٬٢٣٤٫٥` إلى النص `'1234.5'`. لا يعامل التوجيه الفاصلة `,` كنقطة عشرية. وإذا غيّرت الإعدادات، تُطبَّق القيم الجديدة عند التعديل التالي للحقل.

## إدخال المبالغ مع `v-model`

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { vDigits } from 'vue-rtl-kit'

const amount = ref<number | string>('')
</script>

<template>
  <label>المبلغ <input v-model.number="amount" v-digits="{ decimal: true }" inputmode="decimal"></label>
</template>
```

مع `v-model.number` اختر `'latn'` وفعّل `decimal: true` حتى يصل المبلغ `١٢٫٥` إلى Vue على شكل النص `'12.5'`، فتحوّله Vue إلى العدد `12.5`. التوجيه نفسه لا يحلّل المبلغ ولا يتحقّق من صحّته. أمّا لقراءة مبلغ منسَّق يحتوي على فواصل الآلاف الخاصة بلغة معيّنة، فاستخدم [`parseNumber()`](/ar/guide/use-format#parsing-numbers). ومع `v-model.lazy` يتغيّر شكل الأرقام في الحقل أثناء الكتابة، لكن Vue تنتظر الحدث `change` لتحدّث قيمة النموذج بدلًا من تحديثها عند كل حدث `input`.

## الحقول وسلوك التحرير

- ضع التوجيه على حقل إدخال نصّي أو على `<textarea>`، لا على العنصر المحيط بالحقل. إذا كان العنصر غير مدعوم فلن يغيّر التوجيه شيئًا، وسيظهر تحذير في بيئة التطوير. لا يصل إلى التوجيه في حقل `type="number"` إلا ما يقبله المتصفّح؛ فقد يتجاهل المتصفّح الأرقام الهندية أو الفارسية قبل أن يتمكّن التوجيه من تحويلها. لإدخال المبالغ بهذه الأرقام، استخدم `type="text"` مع `inputmode="decimal"`.
- إذا عدّلت النص في وسط الحقل، بقي المؤشر في موضعه وبقي التحديد كما هو في الحقول التي تتيح ذلك. مثلًا، إذا حدّدت `XX` في `AB-XX-CD` ولصقت `١۲٣`، أصبحت القيمة `AB-123-CD` واستقرّ المؤشر بعد `3` مباشرةً. وإذا لم يحتج النص إلى تحويل، تولّى المتصفّح اللصق كالمعتاد.
- عند استخدام محرّر أساليب الإدخال (IME)، لا يغيّر التوجيه النص أثناء تركيبه، بل ينتظر حتى يؤكّد المستخدم إدخاله.
- لا يغيّر التوجيه القيمة الأولية، لا عند العرض على الخادم ولا عند تركيب الحقل في المتصفّح. إذا أردت عرض رقم الطلب بالأرقام الغربية منذ البداية، فحوِّله باستدعاء `transliterateDigits(initialReference, 'latn')` عند إعداد القيمة الأولية للنموذج.
