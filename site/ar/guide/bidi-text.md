# BidiText

يقسّم `<BidiText>` النص العادي مختلط الاتجاهات إلى مقاطع، ويعزل المقاطع التي كانت خوارزمية Unicode ثنائية الاتجاه ستعيد ترتيبها لولا ذلك. وهو يعالج ترتيب العرض دون تغيير السلسلة النصية المصدر.

```vue
<script setup lang="ts">
import { BidiText } from 'vue-rtl-kit'

const message = 'آخر تحديث 12-05-2024 بواسطة الفريق'
</script>

<template>
  <p>{{ message }}</p>
  <BidiText as="p" :text="message" />
</template>
```

قد يعيد الفقرة الأولى ترتيب التاريخ بصريًا داخل النص العربي. أما الفقرة الثانية فتستخدم عناصر `<bdi>` حول المقاطع التي تحتاج إلى العزل.

## الخصائص

| الخاصية | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `text` | `string` | `undefined` | النص المطلوب عرضه. عند إغفاله، يُستخدم محتوى الخانة الافتراضية النصي العادي. |
| `as` | `string` | `'span'` | العنصر المطلوب عرضه. |
| `dir` | `Direction \| 'auto' \| undefined` | نطاق الاتجاه الحالي | اتجاه الأساس. يستخدم `'auto'` كشف أول محرف قوي الاتجاه. |
| `strategy` | `'element' \| 'chars'` | `'element'` | إنشاء عناصر `<bdi>` أو محارف تحكم Unicode. |
| `enabled` | `boolean` | `true` | اضبطه على `false` لعرض النص دون تعديل. |

## الخانات والاتجاه

```vue
<BidiText as="p" dir="rtl">
  الإصدار v1.2.3 متاح الآن
</BidiText>

<BidiText dir="auto" text="example.com/ar/pricing — الدليل" />
```

يمكن أن تحتوي الخانة على نصوص وتعليقات وأجزاء. إذا احتوت على وسوم عناصر، فإن BidiText يترك تلك الوسوم دون تغيير بدلًا من تحويلها إلى نص عادي. استخدم الخاصية `text` عند الحاجة إلى العزل.

## الاستراتيجيات

تنشئ الاستراتيجية الافتراضية `element` عناصر مثل:

```html
<span>الإصدار <bdi dir="ltr">v1.2.3</bdi> متاح الآن</span>
```

استخدم `chars` عندما يجب أن يبقى الناتج سلسلة نصية عادية واحدة:

```vue
<BidiText text="الإصدار v1.2.3 متاح الآن" strategy="chars" />
```

يُدرج هذا الوضع محارف `LRI`/`RLI` و`PDI` في النص المعروض. يُفضَّل استخدام العناصر في HTML الاعتيادي، لأن محارف التحكم لا تدخل في النص المنسوخ.

## مقارنة الناتج الخام بالناتج المعزول

```vue
<BidiText as="p" text="رقم الطلب #4821-B" :enabled="false" />
<BidiText as="p" text="رقم الطلب #4821-B" />
```

بالنسبة إلى السلاسل النصية التي لا يمكن أن تحتوي على عناصر، استخدم [واجهة `isolateRuns` البرمجية](/ar/api) مباشرةً.
