# اختصار النص

تختصر البطاقات والجداول والقوائم الأسماء الطويلة بعبارة `name.slice(0, max) + '…'`. لكن `slice` تعدّ وحدات UTF-16، فتفصل الحرف عن تشكيله (`مُحَمَّدٌ` تصبح `مُحَمّ` مع علامة معلّقة في الهواء)، وتقطّع متتالية ZWJ في الرموز التعبيرية (`👨‍👩‍👧‍👦`) أو العلم (`🇪🇬`) إلى محارف مشوّهة، وعندما يُقتطع نص RTL داخل تخطيط LTR تترك علامة الحذف في الطرف الأيمن المرئي، بعيدًا عن الموضع الذي انتهى فيه النص فعليًا.

`truncateText` دالة نقية (دون أي استيراد من Vue) تعدّ وتقصّ بعناقيد المحارف عبر `Intl.Segmenter`، وتزيل المسافات البيضاء والتطويل من النهاية قبل علامة الحذف، وتحسب علامة الحذف ضمن الحد الأقصى، ويمكنها تغليف النتيجة بعازل اتجاه لتبقى علامة الحذف في النهاية المنطقية للنص في أي من الاتجاهين.

```ts
import { truncateText } from 'vue-rtl-kit'

truncateText('مُحَمَّدٌ عَبْدُ اللَّهِ', 5) // 'مُحَمَّدٌ…' — لا تفصل الشدّة عن حرفها أبدًا
truncateText('مرحبا بالعالم', 20)          // 'مرحبا بالعالم' — النص يسع الحد فيعود كما هو
```

## عناقيد المحارف لا وحدات الترميز

العنقود الواحد هو ما يسمّيه القارئ «حرفًا واحدًا»: حرف أساسي مع كل علاماته، أو متتالية ZWJ في رمز تعبيري، أو زوج مؤشرات إقليمية يشكّل علمًا. لا يقع القصّ داخل عنقود أبدًا.

```ts
truncateText('مُحَمَّدٌ عَبْدُ اللَّهِ', 5) // 'مُحَمَّدٌ…' (أربعة عناقيد + علامة الحذف)
truncateText('שָׁלוֹם עֲלֵיכֶם', 5)         // 'שָׁלוֹם…' — نقاط التشكيل العبرية تبقى ملتصقة
truncateText('ﻻ إله إلا الله', 2)          // 'ﻻ…' — وصلة اللام-ألف عنقود واحد
truncateText('١٢٣٤٥٦', 4)                  // '١٢٣…' — كل رقم عربي هندي عنقود واحد
truncateText('۱۲۳۴۵', 3)                   // '۱۲…' — والأرقام الفارسية كذلك
truncateText('👨‍👩‍👧‍👦🇪🇬🎉🎉', 3)             // '👨‍👩‍👧‍👦🇪🇬…' — العائلة والعلم يبقيان كاملين
truncateText('الإصدار v1.2.3 متاح الآن', 10) // 'الإصدار v…' — نص مختلط عربي وإنجليزي
```

تُزال المسافات البيضاء والتطويل (`U+0640`) من نهاية المقطوع قبل علامة الحذف، فلا تنتهي النتيجة بـ `مرحباـــ…` ولا بمسافة معلّقة:

```ts
truncateText('مرحبا بالعالم', 7)      // 'مرحبا…' وليس 'مرحبا …'
truncateText('مرحباـــ بالعالم', 8)   // 'مرحبا…' وليس 'مرحباـــ…'
```

## علامة الحذف محسوبة ضمن maxLength

لا تتجاوز النتيجة `maxLength` عنقودًا أبدًا، بما فيها العلامة. العلامة الافتراضية هي المحرف الواحد `U+2026`؛ مرّر `ellipsis` لتغييرها، وتُحسب عناقيد العلامة نفسها ضمن الحد. وعندما تملأ العلامة وحدها الحد الأقصى تُعاد بمفردها.

```ts
truncateText('abcdefgh', 5, { ellipsis: '...' }) // 'ab...' (اثنان + ثلاثة = خمسة)
truncateText('مرحبا', 1)                          // '…'
truncateText('abcdef', 3, { ellipsis: '' })       // 'abc' — بلا علامة
```

## وضع الكلمات

يقصّ `unit: 'word'` عند آخر حدّ كلمة يسع الحد الأقصى بدل القصّ في منتصف الكلمة. وعندما تكون الكلمة الأولى وحدها أطول من الحد، يعود إلى القصّ بعناقيد المحارف بدل إعادة لا شيء. تأتي حدود الكلمات من `Intl.Segmenter`، فمرّر `locale` للغات التي لا تفصل بين كلماتها بمسافات.

```ts
truncateText('مرحبا بالعالم يا أصدقاء', 14, { unit: 'word' }) // 'مرحبا بالعالم…'
truncateText('مرحبا بالعالم يا أصدقاء', 8, { unit: 'word' })  // 'مرحبا…' — كلمة 'بالعالم' لا تسع
truncateText('الاستخدامات', 4, { unit: 'word' })              // 'الا…' — كلمة واحدة طويلة، فيعود إلى العناقيد
truncateText('الإصدار v1.2.3 متاح الآن', 15, { unit: 'word' }) // 'الإصدار v1.2.3…'
truncateText('سلام دنیا، حال شما چطور است؟', 10, { unit: 'word', locale: 'fa' }) // 'سلام دنیا…'
truncateText('สวัสดีชาวโลกทุกคน', 7, { unit: 'word', locale: 'th' }) // 'สวัสดี…' — التايلاندية بلا مسافات
```

## إبقاء علامة الحذف في النهاية المنطقية

في فقرة LTR تكون علامة `…` اللاحقة لمقطع RTL محرفًا محايدًا يُحسم اتجاهه وفق اتجاه الفقرة، فتظهر في الطرف الأيمن المرئي رغم أن النص قُطع عند نهايته المنطقية (اليسرى). يغلف `isolate: true` النتيجة بـ `FSI ... PDI` (`U+2068` / `U+2069`)، وهو العازل نفسه الذي تصدره [`isolate()`](/ar/guide/text-helpers)، فتبقى علامة الحذف حيث وقع القصّ في الاتجاهين.

```ts
truncateText('الإصدار التجريبي من المكتبة متاح الآن', 12, { isolate: true })
// '\u2068الإصدار الت\u2026\u2069' — علامة الحذف في الطرف الأيسر المرئي داخل بطاقة LTR
truncateText('Release notes for the library', 12, { isolate: true })
// '\u2068Release not\u2026\u2069' — علامة الحذف في الطرف الأيمن المرئي كما هي
```

محرفا العزل محارف تنسيقية: لا تُحسب ضمن `maxLength`. ويُطبَّق العزل على كل مسارات الإرجاع لمدخل صالح — النص الذي يسع الحد، والنص المقطوع، والنتيجة المكوّنة من علامة الحذف وحدها — وعلى علامة الحذف المُعادة عند `maxLength` غير الصالحة في الإنتاج. ومن دون `isolate` يُعاد النص الذي يسع الحد كما هو.

## الخيارات

```ts
interface TruncateOptions {
  ellipsis?: string // الافتراضي '…' (U+2026)؛ تُحسب ضمن maxLength
  unit?: 'grapheme' | 'word' // الافتراضي 'grapheme'
  locale?: string // لغة BCP 47 تُمرَّر إلى Intl.Segmenter
  isolate?: boolean // الافتراضي false؛ تغليف النتيجة بـ FSI ... PDI
}
```

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `ellipsis` | `'…'` (`U+2026`) | العلامة المضافة عند القصّ؛ تُحسب عناقيدُها ضمن `maxLength`. |
| `unit` | `'grapheme'` | يقصّ `'word'` عند آخر حدّ كلمة يسع الحد، مع العودة إلى العناقيد للكلمات الأطول من الحد. |
| `locale` | افتراضي بيئة التشغيل | لغة BCP 47 تُمرَّر إلى `Intl.Segmenter`؛ حدود الكلمات تختلف باختلاف اللغة. والوسم غير الصالح (مثل `'!!'`) يعود إلى اللغة الافتراضية لبيئة التشغيل بدل رمي خطأ. |
| `isolate` | `false` | تغليف النتيجة بـ `FSI ... PDI` لتبقى علامة الحذف في النهاية المنطقية؛ ويشمل النص الذي يسع الحد والنص المقطوع ونتيجة علامة الحذف وحدها على حد سواء. |

## البديل عند غياب Intl.Segmenter

عندما لا يتوفر `Intl.Segmenter` (المتصفحات القديمة وبعض بيئات SSR المصغّرة) تعدّ الدالة وتقصّ بنقاط ترميز Unicode عبر `Array.from`. لا تُفصل أزواج الوكلاء (surrogate pairs) أبدًا، لكن **قد** ينفصل الحرف الأساسي عن علاماته و**قد** تنكسر متتالية ZWJ. ويظل وضع الكلمات محترمًا للكلمات: يقصّ عند آخر حدّ مسافة بيضاء يسع الحد (أطول بادئة كلمات كاملة، مع حساب علامة الحذف)، ويعود إلى القصّ بنقاط الترميز عندما تكون كلمة واحدة أطول من الحد. أما ما عدا ذلك — ميزانية علامة الحذف، والتشذيب، والعزل، وعقد `maxLength` — فيسلك السلوك الموثق نفسه. وعلى الخادم لا تلمس الدالة DOM أبدًا، فهي آمنة في أي عرض SSR.

## قيم maxLength غير الصالحة

يجب أن يكون `maxLength` عددًا صحيحًا لا يقل عن 1. في بيئة التطوير ترمي القيمة غير الصالحة خطأ `TypeError`؛ أما في الإنتاج (`NODE_ENV === 'production'` أو بناء متصفح بلا كائن `process` عام) فتُعاد سلسلة علامة الحذف بدلًا من ذلك — مغلّفة بـ `FSI ... PDI` عند `isolate: true` — فتتحول القيمة الخاطئة إلى علامة بدل إسقاط العرض.

```ts
truncateText('مرحبا', 0)   // TypeError في التطوير
truncateText('مرحبا', 2.5) // TypeError في التطوير؛ '…' في الإنتاج
```

راجع [مرجع API](/ar/api#truncate-text) للاطلاع على التوقيع الكامل.
